# vouchnotes
A music recommendation utility made with Flask, Firebase Auth &amp; SQL Connect

### Demo
<img width="800" height="450" alt="post1-ezgif com-video-to-gif-converter" src="https://github.com/user-attachments/assets/dff35f8a-a960-4254-b98b-283b12702a75" />

### Functionality 

- Users can sign up and sign in
- Users can search the Discogs music library
- Users can recommend music and see recommendations of other users
- Users can follow each other
- Users can like recommendations made by others
